# VEYRA — Living Intelligent Reality\n\nThis branch contains the first runnable browser vertical slice of Veyra.\n\n## Run\n\n`npm install` then `npm run dev`, and open `/veyra`.\n\n## Implemented\n\n- Cinematic threshold: emergence → VEYRA → Enter.\n- No conventional dashboard, map, avatar picker, or game loop.\n- Oryn: browser speech perception through Web Speech API when available.\n- Thren: visible signal field representing relationships and discoveries.\n- Vael: an unfinished thought becomes a named spatial phenomenon.\n- Elyth: created phenomena persist in localStorage as spatial memory.\n- Procedural positions, hue, scale, pulse and ambient motion.\n- Memory inspection by clicking a created signal.\n\n## Core rule\n\nThe world does not answer the thought; the world changes because of it.\n\n## Next production layer\n\nMove the same state model into a real-time renderer and server-side world state:\n\nVisitor → Oryn → Thren → Vael → Veyra → Visitor\n\nKeep model providers replaceable. Veyra owns identity, memory, concepts, relationships, transformations and world state.\n
